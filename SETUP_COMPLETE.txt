NOT Required:

  • Admin access (usually)
  • Development tools
  • Any external dependencies

📞 TROUBLESHOOTING

If PyInstaller install fails in SETUP.bat:
  Open PowerShell and run:
  pip install pyinstaller

If BUILD.bat fails:
  Check error message and ensure:
  • All required folders exist
  • db.sqlite3 exists or can be created
  • Python path is correct

If EXE won't run on target system:
  • Check Windows version (need 10/11 64-bit)
  • Try running as Administrator
  • Ensure .NET Framework installed
